📊 Simulador: Componentes de Varianza y el Teorema del Límite Central

Herramienta didáctica para visualizar cómo el ANDEVA separa la variabilidad real entre grupos del "ruido" aleatorio, aprovechando la compresión de la varianza que predice el TLC.

⚙️ 1. Configuración de la Población

Más muestras = mayor compresión del ruido (TLC).

El "ruido" o variabilidad natural entre individuos.

La diferencia real y sistemática entre los tratamientos.

💡 El Principio Clave (TLC)

Si tomamos muchas muestras, la varianza de las medias muestrales no es σ² dentro, sino que se comprime por el tamaño de muestra:

Varianza del error de la media = σ² dentro / n
Por eso, al multiplicar la varianza de las medias por n, "descomprimimos" el ruido y podemos restarlo para aislar la varianza real entre grupos.

A. Muestra de Individuos (Datos crudos)

Líneas discontinuas = Medias verdaderas | Líneas continuas = Medias muestrales

B. Efecto TLC: Distribución de las Medias

Observa cómo la dispersión de las medias es menor que la de los individuos.

🧮 2. Desglose del Cálculo ANDEVA (Estimación)

Paso 1: Estimar el "Ruido" (CME)

El Cuadrado Medio del Error promedia las varianzas dentro de cada grupo. Es un estimador insesgado de σ² dentro.

CME = 31.02 ≈ σ² dentro

Paso 2: Varianza Observada de las Medias

Calculamos la varianza muestral de las 3 medias de grupo obtenidas.

Var(x̄) = 42.25

Paso 3: Escalar al nivel de Cuadrados Medios (CMG)

Multiplicamos por n para "descomprimir" el efecto del TLC y obtener el Cuadrado Medio de los Grupos.

CMG = n × Var(x̄) = 422.47

Teóricamente: E[CMG] = σ² dentro + n(σ² entre)

Paso 4: Despejar la Varianza Entre Grupos

Restamos el ruido (CME) del total (CMG) y dividimos por n para aislar el efecto real.

σ² entre estimada = (CMG - CME) / n
= (422.47 - 31.02) / 10
= 39.15

Valor real poblacional: 30

⚠️ Nota didáctica: El estimado es ligeramente negativo (mostrado como 0). Esto es normal en ANOVA cuando la varianza entre grupos real es muy baja y el error aleatorio hace que CME > CMG en una muestra específica.
